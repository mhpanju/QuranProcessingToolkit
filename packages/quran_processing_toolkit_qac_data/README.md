# Quran Processing Toolkit — QAC data

This distribution contains verbatim source data for
[`quran-processing-toolkit`](https://github.com/mhpanju/QuranProcessingToolkit):

- Quranic Arabic Corpus morphology version 0.4;
- Tanzil Uthmani Quran text version 1.1; and
- the toolkit's Apache-2.0 juz-boundary table.

The morphology and Quran text retain their complete embedded copyright notices.
They are not licensed under Apache-2.0. See the files installed in the distribution's
`licenses` directory and `THIRD_PARTY_NOTICES.txt`.

No translation is included. Users may supply a translation separately to the core
toolkit, subject to that translation's terms.
